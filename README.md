## 🏗️ Project Architecture

The project follows a professional, scalable structure to ensure easy maintenance:

```text
/ (Root)
├── index.html               # Entry shell
├── assets/                  # Optimized static assets
└── src/
    ├── data/
    │   └── portfolio.js      # Source of truth (All content lives here)
    ├── styles/
    │   ├── main.css          # Global variables & palette
    │   ├── layout.css        # Structure & Grid
    │   ├── components.css   # Glassmorphism & UI elements
    │   └── animations.css    # Smooth transitions
    └── js/
        ├── main.js           # Logic to render data into DOM
        └── animations.js     # Scroll & interaction effects
```
